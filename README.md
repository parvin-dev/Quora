# Quora - Q&A Application

A Quora-style application built with Node.js and Express.js to learn backend development and CRUD operations.

## Features
- Create, view, edit, and delete posts
- View individual posts

## Tech Stack
- Node.js and Express.js
- EJS
- HTML, CSS, JavaScript

## Getting Started

```bash
git clone https://github.com/parvin-dev/Quora.git
cd Quora
npm install
node app.js
```

Open `http://localhost:8080` in your browser (use the port configured in `app.js`).
